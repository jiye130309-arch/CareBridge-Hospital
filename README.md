# CareBridge Hospital Web Migration

Programming 1 Project Part B

A modern web-based hospital system developed using Python Flask.

## Project Modules

- Git & GitHub
- Web Redesign & AI Refactoring
- Docker Deployment
- ngrok Public Roll-out Simulation
- AI Assistance

## How to run the website

1. Open a terminal in the project folder.
2. Install packages: `pip install -r requirements.txt`
3. Start the app: `python app.py`
4. Open http://127.0.0.1:5000 in a web browser.
